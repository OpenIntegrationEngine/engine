🎉 Installation Complete - Next Steps

Congratulations! Open Integration Engine has been successfully installed on your system.

📋 What's Next?

Step 1: Start the Server

Depending on your operating system, follow these instructions to start the Open Integration Engine server:

🪟 Windows

Option A: Using the Service (Recommended)

  • The OIE service is installed and configured to start automatically
  • After installation completes, the service will start automatically
  • To manually manage the service:
    • Open Services (services.msc) or use the Server Manager
    • Find "Open Integration Engine Service"
    • Right-click and select "Start", "Stop", or "Restart"

Option B: Using PowerShell/Command Line

sc start oieservice

Or navigate to the installation directory and run:

.\oieserver.ps1

🍎 macOS

Using the Service (Recommended)

  • The OIE service is installed and configured to start automatically
  • Important: A system reboot is required for the service to start automatically
  • Alternatively, you can start the server manually from the installation directory:
./oieserver

🐧 Linux

Option A: Using systemd (Recommended)

  • The OIE service is installed and configured to start automatically
  • To manually manage the service:
sudo systemctl start oieservice
sudo systemctl status oieservice

Option B: Manual Start

Navigate to the installation directory and run:

./oieserver

Step 2: Access the Administrator Console

Once the server is running, you can access the Administrator Console:

  • Web Browser: Navigate to http://localhost:8080
  • Click the "Launch Administrator" button
  • This will download and launch the administrator client application

🖥️ Desktop Launcher (Windows)

On Windows, you can also launch the Administrator directly from:

  • Start Menu → Open Integration Engine → OIE Manager
  • Or run oiemanager.exe from the installation directory
⚠️ Default Credentials:
Username: admin
Password: admin

Please change these credentials immediately after your first login for security purposes!

Step 3: Verify Installation

To confirm the server is running properly:

  1. Check that the server is listening on ports 8080 (HTTP) and 8443 (HTTPS)
  2. Review the logs in the logs directory for any errors
  3. Log in to the Administrator Console and verify you can access the Dashboard

📁 Important Directories

Directory Purpose
conf/ Configuration files including mirth.properties
logs/ Server log files
appdata/ Application data and embedded database
extensions/ Installed plugins and connectors
custom-lib/ Custom user libraries for channel scripts

🔧 Configuration

Key configuration settings can be found in conf/mirth.properties:

  • Ports: Default HTTP (8080) and HTTPS (8443)
  • Database: Embedded Derby by default
  • Application data path: Configurable via dir.appdata
Note: If you need to change configuration settings, stop the server first, edit the configuration files, and then restart the server.

❓ Troubleshooting

Server Won't Start?

  • Check the logs in the logs/ directory for error messages
  • Ensure ports 8080 and 8443 are not already in use by another application
  • Verify that Java 17 or higher is properly installed and accessible
  • Check file permissions on the installation directory

Can't Access Administrator Console?

  • Verify the server is running by checking the service status or logs
  • Ensure your firewall isn't blocking ports 8080 or 8443
  • Try accessing via IP address instead of localhost
  • Clear your browser cache and try again
