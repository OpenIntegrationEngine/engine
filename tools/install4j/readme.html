Open Integration Engine ${compiler:sys.version}

This installer sets up a fully functional version of the engine with minimal user input, or upgrades an existing installation. The installer requires administrator permissions to run and install services.

Notes

  • Native services are installed for all supported platforms and are configured to start automatically on boot.
  • An option will be provided to start the service immediately after installation.
  • A new installation uses the default configuration files in the conf directory; the installer does not prompt for customization. This includes ports (default: 8080 and 8443), log and app data paths, and password requirements.
  • An upgrade replaces the program files after uninstalling the previous installation. Files in the conf directory are kept and are not updated with new defaults. Directories created at runtime, such as appdata, are also kept.
